# Prototipo de nivel medio: registro de causas 6M (Two Glass)

Prototipo navegable en un solo archivo (`index.html`) de la plataforma de registro de causas de defectos para Two Glass S.A.S. BIC. Proyecto Integrador I, equipo TeamGlass, Pontificia Universidad Javeriana Cali.

- Datos de ejemplo, sin base de datos ni login.
- Se cambia entre las vistas "Producción (TV)", "Gerencia" y "Pruebas con usuarios".
- Los resultados de las pruebas se guardan solo en el navegador (localStorage); descargar el CSV al terminar cada sesión.
- La plataforma funcional (nivel alto) está en https://github.com/Niko2361920/prototipo_alta
